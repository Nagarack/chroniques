CHRONIQUES - MIGRATION VERS UNE NOUVELLE VERSION

DEPUIS LA 3.9 : fermez le serveur et glissez le ZIP de la nouvelle version sur METTRE_A_JOUR.bat.
Tout est automatique (sauvegarde, verification, retour arriere). La methode ci-dessous ne sert
qu'une derniere fois, pour passer d'une version plus ancienne a la 3.9.

1. Sauvegarder l'ancienne version (SAUVEGARDER_CHRONIQUES.bat), puis arreter completement son serveur.
2. Extraire la nouvelle version dans un NOUVEAU dossier VIDE.
3. Double-cliquer MIGRER_DONNEES.bat, puis indiquer l'ancien dossier (celui qui contient server.js).
   Sont copies : la base de donnees, la configuration HTTPS et les images (data\media).
4. La copie refuse d'ecraser une base deja presente dans le nouveau dossier.
5. Demarrer avec DEMARRER_CHRONIQUES.bat, puis verifier campagnes, personnages, images et permissions.
6. Conserver l'ancien dossier et sa sauvegarde pour un retour arriere.
7. La configuration Cloudflare reste identique : tunnel HTTP vers 127.0.0.1:8080.
8. Lire GUIDE_TESTEURS.md et garder les identifiants et codes d'invitation prives.
